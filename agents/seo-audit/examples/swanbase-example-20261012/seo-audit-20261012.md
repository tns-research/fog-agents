## Summary

The program page tells Google it is a copy of the home page (canonical to `/`), so it cannot rank for the queries it already gets impressions on. The blog post on first pitches lost most of its clicks after dropping from position 4.2 to 7.8 on its main query (`bands.md`), while a second post carries the same title and an invalid JSON-LD block. Fix the canonical, the duplicate title and the slash duplicate first, then refresh the first-pitch post at its current URL.
