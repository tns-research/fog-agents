# Report template

`market-signal-<YYYYMMDD>.md` is generated by `scripts/build_handoff.py` from the run folder; it is not filled by hand. This file lists its sections, where each one comes from, and what the model may edit after the build. Generated example: [`../examples/swanbase-preseed-fundraising-20261012/market-signal-20261012.md`](../examples/swanbase-preseed-fundraising-20261012/market-signal-20261012.md).

| Section | Source | Model may edit |
|---------|--------|----------------|
| Title and header line (project, date, window, language, geography, valid until) | `analysis.json`, `stats.json` | no |
| Summary | `analysis.json` `summary` (no number), then the escalated pains with their computed counts and the rule | no: interpretation goes in `summary`, then rebuild |
| Sources and health | `health.json`: status per collector job, records, capped, note; records and voices by source with shares; sentiment counts | no |
| Pains | `stats.json` per pain: escalated, distinct authors, communities, voices, by source, first and last seen, trend, volume | no |
| Weak signals, rejected pains | pains under the threshold; `analysis.json` `rejected_pains` | no |
| Quotes | verified quotes grouped by pain, in blockquotes, each with quote id, community, date, speaker, length, permalink | no |
| Hooks, objections, angles | `analysis.json`, with lengths from the build | no |
| Persona and forces | `analysis.json` persona, forces as quote ids ("absent in this corpus" when empty), force counts from `stats.json` | no |
| Existing solutions | `analysis.json` with mention counts from the labels | no |
| Language bank | `stats.json` (or the line saying no phrase reached the threshold) | no |
| Changes since the last run | `changes.json` (watch mode) | no |
| Recommendations | `analysis.json`, each with "False if" | no |
| Methodology | generated: collection, coding, counting rule, verification result, schema | yes, at the very end of the run only: the results of the checks of Step 7 are appended (writing gate, claims, fresh eyes, run log), after the last rebuild |
| Limitations | `analysis.json` `limitations`, then every collector not `ok`, capped collectors, the public-discourse caveat | no |

Rules:

- A number in the report comes from `stats.json`, `health.json` or `changes.json`. To change a number, change the labels or the collection and rebuild.
- A quote, hook or objection sits in a blockquote: the writing gate skips it and nobody rewrites it.
- A force or a section with nothing behind it says so in one line; it is never filled.
- To change the report, edit `analysis.json` or `labels.jsonl` and run `python3 scripts/build_handoff.py --run <run>` again.
